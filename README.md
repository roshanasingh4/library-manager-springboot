# Library Manager

A Spring Boot application that manages **Authors** and **Books** with Create, Read and Update operations, JSP views and unit tests.

**Student:** Roshan Avadhesh Singh
**Roll No.:** 2024eb03006

## Features

- **Entities:** `Author` (one) to `Book` (many), mapped with JPA (`@OneToMany` / `@ManyToOne`), unique e-mail and unique ISBN constraints.
- **Populate database:** tables are generated by JPA and `DataSeeder` inserts 10 authors and 10 books at start-up.
- **Create:** JSP forms for adding authors and books, with Bean Validation and friendly handling of integrity violations (duplicate e-mail / ISBN).
- **Read:** list pages bound with JSTL/EL. The books page and the overview page use custom **INNER JOIN** queries in the repository layer.
- **Update:** edit forms for both entities, with the same validation and integrity checks.
- **Tests:** `@DataJpaTest` repository tests and Mockito service tests (25 tests).

## Tech stack

Java 21, Spring Boot 3.3.5, Spring MVC, Spring Data JPA (Hibernate 6), H2 in-memory database, JSP + JSTL, JUnit 5, Mockito, AssertJ.

## Project structure

```
src/main/java/com/roshan/library
  entity/        Author, Book
  repository/    AuthorRepository, BookRepository (custom JPQL inner joins)
  service/       AuthorService, BookService (business logic, integrity checks)
  controller/    HomeController, AuthorController, BookController
  dto/           BookForm, BookAuthorView, AuthorSummary
  exception/     DuplicateResourceException, ResourceNotFoundException, GlobalExceptionHandler
  config/        DataSeeder (10 rows per table)
src/main/resources/META-INF/resources/WEB-INF/jsp   JSP views
src/main/resources/static/css/app.css               Stylesheet
src/test/java/...                                    Repository and service tests
```

## Run

```bash
mvn spring-boot:run
```

Open http://localhost:8080. The H2 console is at http://localhost:8080/h2-console (JDBC URL `jdbc:h2:mem:librarydb`, user `sa`, empty password).

## Test

```bash
mvn test
```

## Main routes

| Method | Path | Purpose |
|---|---|---|
| GET | `/` | Overview with inner-join summary of authors and book counts |
| GET | `/authors` | List authors |
| GET / POST | `/authors/new`, `/authors` | Add an author |
| GET / POST | `/authors/{id}/edit`, `/authors/{id}` | Update an author |
| GET | `/books?genre=` | Books joined with their authors (inner join), optional genre filter |
| GET / POST | `/books/new`, `/books` | Add a book |
| GET / POST | `/books/{id}/edit`, `/books/{id}` | Update a book |

Screenshots of every operation are in [`docs/screenshots`](docs/screenshots).
